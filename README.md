# Luigi's Ristorante & Sportbar: digital menu

QR menu with WhatsApp ordering. Live at https://cesarbarroetacamacho.github.io/luigis-menu-v4/

- Add `?mesa=N` to the URL to preload the table number (for example `?mesa=7`).
- Menu data lives in the `var MENU = {...}` block inside `index.html`.
- Photo sources and licenses (all CC0): `img/luigis-v4/FUENTES.txt`.
